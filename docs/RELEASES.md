# ORHAR Website Releases

This file tracks notable website releases.

## Release process

1. Create a branch.
2. Make changes.
3. Test locally.
4. Push branch.
5. Validate Cloudflare Preview Deployment.
6. Merge into main.
7. Confirm production at https://orhar.com.
